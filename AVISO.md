# ⚠️ Aviso de uso responsable

Este proyecto (**Veridia**) es una **demostración académica** de la experiencia de
usuario de un flujo de verificación de identidad. Léelo antes de usar, desplegar o
modificar el código.

## 1. Naturaleza del proyecto

- Es material **educativo**, desarrollado para un trabajo universitario.
- Contiene **solo la interfaz y la lógica que corre en el navegador**. No incluye
  backend, base de datos ni ningún mecanismo de transmisión o almacenamiento de
  datos.
- No es un producto terminado ni una solución de verificación de identidad apta
  para producción.

## 2. Privacidad y datos

- Tal como está publicado, el proyecto **no recopila, envía ni guarda** imágenes ni
  datos personales. Todo el procesamiento ocurre localmente y la información se
  pierde al cerrar o recargar la página.
- El rostro de una persona y su documento de identidad son **datos personales
  sensibles**. Su tratamiento está regulado (por ejemplo, la **Ley 1581 de 2012** y
  sus decretos en Colombia, o el **RGPD** en la Unión Europea).

## 3. Condiciones de uso

Si reutilizas o adaptas este código, te comprometes a:

- **No** desplegarlo para capturar el rostro o los documentos de personas reales
  **sin su consentimiento informado, previo y expreso**, y sin una base legal
  válida para tratar datos biométricos.
- **No** usarlo para suplantar la identidad, la marca o la imagen de ninguna
  persona, entidad o institución, ni para inducir a error a quien lo utilice.
- **No** emplearlo para recolectar, almacenar o transmitir datos de terceros con
  fines fraudulentos o no autorizados.
- Cumplir la legislación de protección de datos y demás normativa aplicable en tu
  jurisdicción.
